- [x] автоматический тест test_homework_04 проходит
      
1. homework_04 директория в которой находятся все модели, конфиги и запуск программы.
   1. main.py - основной файл, через который запускаем программу
   2. models директория - в которой описаны создание движка для подключения к БД и наши классы для создания таблиц
2. Dockerfile - в которой описана сборка контейнера с postgresql
      
## Запуск программы
1. Через docker собираем образ и запускаем его
```
docker build . --tag ping
docker run -it -p 5432:5432 ping
```
2. В директории homework_04 запускаем main.py
3. В директории testing/test_homework_04 запускаем test_main.py чтобы прогнать тесты
