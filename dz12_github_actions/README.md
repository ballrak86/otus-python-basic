# Домашнее задание - 6

## Асинхронная работа с сетью и БД

## Задание для выполнения
- [x] На основе `homework_04` создать приложение которое через http запрос получит данные о пользователях и их постах и передаст эти данные в БД
      
1. main.py - основной файл, через который запускаем программу
2. models директория - в которой описаны создание движка для подключения к БД и наши классы для создания таблиц
3. Dockerfile - в которой описана сборка контейнера
      
## Запуск программы
Через docker собираем образ и запускаем его
```
docker build . --tag ping
docker run -it -p 8000:8000 ping
```
Подключаемся через браузер http://127.0.0.1:8000
